## 🎯 Quick Start

### 1. Create Account
```bash
1. Visit oxher.com
2. Click "Sign Up"
3. Verify your email
4. Get 3 free OXH credits
```

### 2. Generate First Signal
```bash
1. Go to Signals page
2. Select trading pair (e.g., BTC/USDT)
3. Choose timeframe (1H, 4H, 1D)
4. Click "Generate Signal"
5. Review AI analysis
```

### 3. Use Vision AI
```bash
1. Upload chart screenshot
2. Select analysis type
3. Get AI insights
4. Apply to your trading
```
